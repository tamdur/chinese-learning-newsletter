Anthropic公布上市價格，估值最高1.4兆美元

來源：Anthropic / CNBC

AI公司Anthropic（Claude的開發公司）11月10日開始向投資人介紹自己，準備在美國Nasdaq股市上市。它打算賣出大約8.25億股，每股70到78美元，股票代號是ANT。

照這個價格算，公司價值大約1.2兆到1.4兆美元，比之前傳出的2兆美元低不少。最後價格預計11月18日決定，隔天就能開始買賣。

這是頂尖AI公司第一次讓大眾買股票。一週前AI股票才大跌，這次上市就像一場大考試。
